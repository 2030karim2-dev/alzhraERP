## 2. ما أُنجز (P0 → P4)

| المرحلة | المحتوى |
|---|---|
| **P0** | viewport-fit + safe-area لكل العناصر السفلية؛ جذر 12px؛ حد أدنى 10px؛ أهداف لمس 44–48px؛ قاعدة 16px للحقول؛ مسح 173 ملفاً؛ إصلاح manifest |
| **P1** | تلميح تمرير أوتوماتيكي لـ 7 جداول؛ بطاقات موبايل (ديون/صندوق)؛ بحث موبايل في الهيدر؛ حارس `check:classes` |
| **P2** | توحيد الألوان (276 موضعاً/159 ملفاً)؛ بطاقات قيود يومية؛ حارس `check:fonts` |
| **P3** | e2e استجابي؛ فحص 390×844 بالأدلة؛ `DhikrTicker max-sm:hidden`؛ إصلاح انجراف Playwright port؛ husky pre-push من 6 حواجز |
| **P4** | `matchMedia`؛ مكوّن `MobileCardList` + توحيد 4 بطاقات (−175 سطر)؛ PWA 192px؛ فحص 320px بالأدلة |

**النتيجة: +1226 سطراً، −918 سطراً عبر 270+ ملفاً** (نصفها تحويلات ألوان/خطوط آلية محكومة).
